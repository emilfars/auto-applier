# Brand assets

Drop screenshots of the previous static website in this folder
(e.g. `home.png`, `feed.png`). They are the visual reference for M4.5.

**`palette.md` is the authoritative token source.** Coding agents read
`palette.md`, not the images — every hex value sampled from the screenshots
must be recorded there before implementation starts (plan.md, M4.5 step 0).

Keep images lossless where possible (PNG). Do not edit screenshots.
